Read the winner correctly

速度最快，不等于应该上线

第一场有显著速度赢家，却被质量门禁挡住；第二场质量传输稳定，却没有实际速度赢家。 默认配置由“性能幅度 × 证据可信度 × 质量门禁”共同决定。

为什么新实验判定为“打平”
Combined wall time 差 5.22 秒 / 约 15.5 分钟，归一化输出吞吐差 0.43%。只有一个 server session / arm，且没有 ABBA 反向顺序重复，因此不把这一级别的差异解释成稳定机制优势。 建议复测门槛为：平衡顺序下，wall time 与 output tok/s 同向且稳定超过 3%。
